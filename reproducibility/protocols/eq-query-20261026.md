## Independent comparisons
Nine arms: bridge_pool; plain_pool, plain_and; entity_pool, entity_and; typed_pool, typed_and; structure_pool, structure_and. The four phenotype-query graph variants have no disease nodes anywhere. bridge_pool adds back only training disease nodes and their associated_with/has_symptom edges to the plain graph; query inputs are still phenotypes. This isolates disease-node removal. Pool-versus-AND within each graph isolates query aggregation. Each EQ graph versus plain under the same readout isolates the added projection.

Plain graph keeps gene–mouse-phenotype observations, training-derived gene–human-phenotype links, phenotype taxonomy/cross-species taxonomy, gene–GO annotations, and a common entity ontology backbone. Remove expression edges from all arms. Remove original phenotype-to-nonphenotype ontology projections, reverse projections, and non-taxonomic phenotype-to-phenotype links, so EQ treatment is not already present in the control. Restrict ontology class namespaces to HP/MP/UPHENO/GO/UBERON/PATO/CL/CHEBI/BFO/CARO/MPATH/BSPO/OBA. Disease identifiers never enter projection inputs. Preserve all candidate genes and query phenotypes, even if isolated.

Frozen local ontology releases: upheno.owl, go.owl, uberon.owl from the earlier recovered ontology directory, with SHA256 and version IRIs retained. Streaming structural OWL parsing, no labels/text heuristics, annotations or gene-specific disease definitions. Extract named subclass and simple existential edges in the common entity backbone. Only supported named/intersection/existential class expressions are projected; reject union, negation, universal/cardinality/value restrictions and unsupported RDF-list syntax, and report omissions.

EQ variants:
- entity: manifest phenotype→GO/Uberon entity links extracted from existential paths, collapsing the path to a generic entity-projection relation. Inverses support phenotype→entity→entity ontology→phenotype navigation. This intentionally loses roles/quality and is not claimed equivalent to OWL entailment.
- typed: phenotype→entity links retain the final restriction's property identity; add separate PATO quality and qualifier links (qualifier identified by RO:0002573 in its restriction path). Still a lossy projection, distinct from the structured arm.
- structure: syntax nodes identified by canonical expression hashes retain existential nesting, intersection members, and subject subclass/equivalent-expression links. Graph traversal over syntax is not an OWL reasoner.
Record axiom ASTs/source files and projection code/input/output hashes. Report direct HP/MP/uPheno projection coverage. Definitions reachable through phenotype taxonomy may add indirect coverage. No claim that every phenotype has an EQ definition or that inferred graph answers are logical entailments.

## Model and supervision
All nine arms start from the same general ultra_4g checkpoint (not an already GDA-fine-tuned checkpoint that has seen richer graph projections). Use upstream ULTRA QueryNBFNet for one-source relation projections. Its weights are compatible with the base entity model; pilot checks score parity on the same graph. Pool readout is learned sigmoid-weighted max/mean of phenotype logits; AND is the numerically stable mean log-sigmoid across unique phenotype branches, rank-equivalent to product conjunction within a query. Mean normalization avoids query-length scale effects. AND is implemented directly in log space instead of upstream epsilon-clipped conversion to logits; this is an explicit task adaptation. Both receive the same sampled multi-positive softmax ranking loss. Full ULTRA weights are updated in every arm; this is not frozen-model inference or an auxiliary feature scorer.

500 updates per fold/arm, AdamW lr1e-5, no weight decay, seed0, gradient norm clip1. Sample a training disease uniformly and up to8 distinct query phenotypes, without replacement. Include all known candidate positive genes,32 uniform negatives,32 hard negatives drawn from256 proposals. Shared sampling RNG policy. Exact two-pass chain rule: compute aggregation gradients from small score matrices then replay each branch with gradients, retaining only one full graph tape. For every training query remove all direct causes_phenotype edges touching any query phenotype in both directions, independent of gene label. In bridge control also remove all incident edges of training disease nodes sharing queried phenotypes. Keep relation meta-graph train-only as in earlier experiments. No random traversal dropout substitutes for deterministic masking.

Evaluation uses full unique phenotype profiles and all candidate genes. Primary calibrated scores use the same leave-one-out query-panel gene normalization as prior work; retain raw sensitivities. Validate at step0 and every100 updates. Retain step0 fallback; eligible checkpoints must not decrease either validation Hits@1 or Hits@10 relative to step0. Among eligible checkpoints maximize Hits@10, Hits@1, MRR, negative MR. Do not select a replacement just because MR improves. Save training progress, optimizer/RNG state and resume checkpoint atomically every10 updates and after validation.

All nine arms ×ten folds =90 training runs. Development fold0 pilots use four validation diseases and two updates, never test metrics. Pilot gate: source/input hashes, candidate integrity, no disease nodes in phenotype-only graphs, backbone parity, finite nonzero parameter updates/gradients, selection logic and peak memory. Run pilot plain_pool, plain_and, structure_and to cover the smallest and largest graph and both readouts. Technical fixes before passing pilots are retained; failed pilot artifacts archived.

All90 training selections are frozen before any new test scoring; no test-driven arm selection. A descriptive preferred EQ AND arm is chosen on mean validation metrics on development folds0,1,2 only; all arms remain reported. After global freeze score all90 checkpoints. Report Hits@1/10,MRR,MR, seen/unseen causal genes, association-pooled/equal-disease/equal-fold metrics. Primary scientific contrasts: plain_pool–bridge_pool (disease nodes), plain_and–plain_pool (AND), entity_and/typed_and/structure_and minus plain_and (EQ), each Hits@1/10: ten contrasts, 99.5% paired disease-cluster bootstrap intervals,10000replicates.
