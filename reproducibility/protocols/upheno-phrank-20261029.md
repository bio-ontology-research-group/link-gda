# UPheno Phrank root-information correction, fixed 29 October 2026

Phrank 1.6 assigns a parentless phenotype its information content, with the number of annotated genes as denominator. The historical UPheno adaptation instead assigned every parentless term zero. This differs on a taxonomy with several roots: in fold 0, the HPO root covers 3,800 of 13,625 human-plus-mouse annotated genes, giving marginal information content 1.8421849062207032 bits under the author rule. The human-only and mouse-only fold-0 designs have no nonzero root contribution. The discrepancy was identified from source and annotation coverage before examining corrected outcomes.

Recompute all ten Phrank variants on all ten frozen folds. For a parentless term use `-log2(number of annotated genes containing the term / number of genes with any annotation)`. For other terms retain the parent-union denominator. Absent terms contribute zero. Annotation unions, training disease-max references, mouse-only conditions, normalization, float32 score matrices and whole-candidate coverage remain the declared UPheno adaptations. Raw scores and each annotation-source configuration remain separately labelled; no scoring choice is selected using test results.

`--phrank-root-policy native` is the corrected default. The explicit `legacy-zero` option reproduces the historical root-suppressed procedure. `--phrank-only` writes only the ten Phrank outputs and their complete source/input hashes, without touching the independent PhenoRank computations. Use new output roots and retain historical outputs unchanged. Compare marginal information content against the author implementation on a forest with singleton terms and unannotated candidates; an actual scoring fixture must show the human-plus-mouse root contribution and verify all ten outputs.

The separately running PhenoRank published-tier rerun is unaffected. Its Phrank outputs use the earlier root convention and must be replaced by this corrected Phrank-only run in the combined report. Native HPO direct and disease-max arms use the author implementation and are separate comparisons.
