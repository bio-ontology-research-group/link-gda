# PhenoRank independent comparison adapter — frozen 2026-10-23

Native algorithm: PhenoRank source9689f593b8a59650d7fa8525af95045744511f6e, default1,000 simulated queries, restart0.1,20 random-walk iterations. Original rank-before-simulation comparison and empirical P floor1/1000 are retained; primary scores are negative P with average ties. Raw propagated scores are a descriptive companion. No test-performance tuning.

Original human disease/GDA caches are NEVER used to construct fold models. Each fold uses only its declared inner-training GDA and disease profiles. All validation/test diseases are absent from reference conditions, information content, human gene weights and phenotype cooccurrence. Retain original mouse-mutant profiles/orthology and PPI network as resource-rich independent evidence. Recompute term IC from ancestor-expanded nonempty human+mouse conditions, condition IC and simGIC matrix. Simulated-query cooccurrence uses directly annotated training human diseases with known genes, matching original cache construction. Archived cache reconstruction is a technical equivalence check only; production never loads human-label or cooccurrence caches.

Frozen ontology compatibility adapter: query and training HPO terms present in the archived phenotype universe retain identity. Others are projected to the most specific available archived ancestors through ONLY frozen ontology subclass/superclass edges, with superclassof direction reversed. Labels and scores do not choose mappings. Retain mappings and unsupported term/profile counts per fold. Profile terms are unique sets (as native semantic similarity); after projection simulation size is the number of distinct represented terms. Profiles without any represented term receive tied zero raw scores and negative-P=-1 for every candidate.

Identifiers: official HGNC complete-set download2026-10-23, approved one-to-one Entrez→Ensembl mapping with snapshot checksum. Original17,293-node network retained. Append full-candidate genes absent from its nodes; missing/ambiguous Ensembl mappings use distinct explicit Entrez placeholders. These appended nodes have no invented PPI or mouse annotations, but can receive permitted training-human annotations. Original network columns/normalization are untouched. On an isolated appended node the native restart recurrence gives0.1×initial score after any iteration; it does not get a fabricated self-loop. Within-query ranking for simulation includes the extended universe, a disclosed full-universe adapter rather than an exact reproduction of the published benchmark. Genes with neither direct annotations nor incoming PPI receive tied no-evidence negative-P=-1; otherwise rank fluctuations of zero-evidence genes would create spurious simulated-query significance. Candidates are never removed.

All13,625 candidates and exact test association rows retained. Seeds derive deterministically from fold,seed0,disease SHA256. No simulated-query reuse or reduced simulation count. Native Python3 port changes only dictionary-key materialization and the undefined terminal Error exception; scoring arithmetic is unchanged. Sampling retains native behavior including replacement in tied cooccurrence groups.

Four single-CPU processes on WS, no GPU. Per-query score chunks and hashes allow explicit source-identical resumption; no automatic retries after failure. Final completion appears only after all query matrices, independently recomputable raw/calibrated metrics and manifests exist. Ten-fold comparison uses the separately frozen comparison/PROTOCOL.md. Pilot used one held-out phenotype query only for timing; its ranks/metrics were not inspected or used for decisions. Method remains exploratory follow-up.
