# Native HPO Phrank baseline

Frozen before computing the ten-fold outcomes. Author Phrank 1.6 direct-gene scoring, unnormalized, is the sole primary setting. The fixed candidate universe, disease profiles, training/validation/test splits and target pairs are copied from the ULTRA campaign. All genes remain candidates; genes lacking training-derived annotations retain zero evidence and average-rank ties.

Ontology: extract only explicit named HPO-to-HPO `rdfs:subClassOf` axioms from the study's retained `upheno.owl`. Preserve its immutable source checksum. Test acyclicity. No OWL2Vec graph, anonymous restriction, cross-species inference or external current annotation file is substituted. Query terms absent from this extracted DAG remain singleton terms under native Phrank semantics, with their coverage reported. Query lists are never dropped. This is a native HPO arm; it does not use the available MGI phenotype evidence and is not presented as a cross-species adaptation or an evidence-identical comparison with multimodal ULTRA.

Gene annotations and information content use only the current fold's training disease–gene links and those diseases' phenotype profiles. Validation and test disease profiles never contribute annotations or IC. Save every annotation's contributing training disease IDs. Use existing frozen gene/disease URIs, introducing no additional disease alias database; this does not establish an exhaustive alias audit of the original input resource.

Invoke the author implementation to compute IC and ancestor closures. Cache closures and retain the author's marginal-information-content intersection formula, using deterministic math.fsum over sorted common terms to preserve equal-overlap ties; validate scores within absolute/relative tolerance 1e-12 against native `compute_phenotype_match` on sampled actual queries and against `rank_genes_directly` on a fixture. No normalization, fitted parameter, phenotype truncation, gene restriction or test-selected option is used. Native Phrank treats input phenotypes as sets through closure, including duplicate phenotype rows.

Write disease-by-gene scores for all outer-test queries in exact candidate order, pairs.tsv, candidates.txt, raw/calibrated metrics, input/source/output checksums, and completion provenance. Raw is primary. Query-panel leave-one-disease-out calibration is a separately labeled descriptive sensitivity using the existing campaign evaluator. Independent rereading must reproduce all reported metrics before completion is written.
