# Archived GeometrE exploration

GeometrE was explored early in this project and was not used for the reported
LinkGDA experiments. This directory preserves its remaining utility module.

- `util.py`: random-seed helper and `FastTensorDataLoader`, moved unchanged from
  the repository root on 29 September 2026.

The repository audit traces this module to commit `ddb50a4`. No current local
source or launcher imports it. No other GeometrE-specific source or configuration
was found in the current code tree, including locally ignored script and sweep
files. Earlier deleted implementations remain in Git history.

This archive is historical code, not an entry point for reproducing the paper.
