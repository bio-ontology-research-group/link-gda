# Archived selection diagnostic

clean_folds_check.py checks an old experiment that selected configurations using
test mean rank on folds 0–2. It hardcodes those historical configurations and
strictly-greater tie handling. The current workflow selects on validation data.

The script was archived unchanged on 29 September 2026. Its input paths are
relative to the working directory. Its opening comments describe the old
experiment, not the current paper.
