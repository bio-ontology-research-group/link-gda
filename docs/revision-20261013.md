## Training

From a code checkout whose `data/` contains the corrected tables, validated graph files and main folds:

```bash
python code/training/kge_transd.py --fold 0 \
  --use_phenotypes --use_functions --use_site --use_graph \
  --projector_name owl2vecstar --graph_policy independent-unique \
  --candidate_pool phenotype --calibration_unit disease \
  --random_seed 0 --val_seed 0 --embedding_dim 200 \
  --batch_size 65536 --learning_rate 0.001 --tolerance 15 \
  --dual_arms --write_baselines --no_sweep
```

Repeat for folds 0–9. Published calibrated-setting hyperparameters are frozen; no revised test result is used to tune them. Dual arms select checkpoints using raw versus calibrated validation MR within the same configuration. This distinguishes selection/scoring effects from hyperparameter changes. Typed negative sampling is off.

For the excluded cohort use a separate data directory and `--candidate_pool function --validation_scope unseen-gene`, omitting `--use_phenotypes`. Run f with functions and graph; fs also includes site. Keep `--val_seed 0` for all initialization/sampling seeds 0–9. Eligibility filtering gives 333 validation associations across 324 diseases whose genes have no training association. Filtered-out validation rows are not moved into training.

Checkpoints carry graph, entity/relation mapping, candidate pool, calibration and validation identity. ConvKB warm-starts must pass the identity check against the matching revised TransD checkpoint. An existing output is an error; use a separate snapshot/output location for a changed implementation.
